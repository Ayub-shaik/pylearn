# Contributing

## Commit Style

Use Conventional Commits:

- feat: new feature
- fix: bug fix
- docs: docs only
- chore: tooling/config
- refactor/test/perf/build

## Branching

- main (protected)
- feat/\*
- fix/\*
- chore/\*

## Workflow

1. Create issue and branch.
2. Implement + tests.
3. `pnpm lint && pnpm typecheck && pnpm test`
4. Open PR using template.
